# 记账标签 Genie Effect 全图层重设计

日期：2026-07-31  
状态：已确认  
替代规格：`2026-07-30-entry-context-genie-transition-design.md` 中的转场渲染部分  
范围：记账页“银行卡、AA、组合支付、优惠”四个标签  
最低系统：项目当前的 iOS 26

## 1. 决策摘要

本设计采用“全区域透明画布 + 合成浮窗图层 + Metal `layerEffect`”架构，
替换当前基于局部联合矩形和 `distortionEffect` 的实现。

已经确认的产品决策：

1. 原始标签是固定、清晰、可读的视觉锚点，在浮窗完全展开后仍然保留。
2. 浮窗打开时，再次点击当前标签会取消草稿并沿原路径收回。
3. 其他标签在浮窗打开期间不可点击。
4. 浮窗外壳、文字、按钮、输入框和当前可见列表内容作为完整合成图层参与形变。
5. 默认动画时长为 `0.62s`，快速起步、柔和减速、无回弹。
6. 键盘始终保持原位和清晰；只在开合动画期间短暂锁定输入。
7. 浮窗最终在标签行上方、键盘上方的可用区域内居中。

## 2. 目标与非目标

### 2.1 目标

- 建立明确的“标签 ↔ 浮窗”空间因果关系。
- 形成可辨识的 macOS Genie / 神奇效果：
  靠近标签的一端先收窄，中段弯曲，完整图层被吸入标签。
- 打开与收回使用同一映射的正反方向，不出现不同路径。
- 消除小白块开场、普通矩形缩放、内容延迟淡入和终点闪帧。
- 在真机上以稳定 `60fps` 为最低性能目标。
- 保留现有草稿、提交/取消、AA 人数输入、组合支付输入和优惠输入逻辑。

### 2.2 非目标

- 不重设计四种浮窗内部信息架构。
- 不修改交易计算、SwiftData Schema 或持久化服务。
- 不把本效果扩展到报销、不计收支、手续费和外币标签。
- 不使用普通 `scaleEffect` 或 `matchedGeometryEffect` 冒充完整模式。
- 不让 Shader 长期挂在记账主页面、标签行或键盘上。

## 3. 视觉与交互设计

### 3.1 静止层级

浮窗打开后，从低到高分为：

1. 原记账内容：模糊、压暗、不可交互。
2. 清晰键盘：保持位置、尺寸和亮度，浮窗稳定后可继续输入。
3. 浮窗或临时 Genie 图层：二者互斥显示。
4. 当前标签副本：固定在记录下来的来源矩形，保持清晰。

原标签行仍在原布局中作为占位，但会处于背景模糊层下。上层标签副本负责视觉
和“再次点击取消”的交互，避免改变横向标签行布局。

其他标签不复制到前景，因此保持模糊轮廓并禁止点击。

### 3.2 打开路径

1. 用户按下标签，标签立即显示现有轻微按压反馈。
2. 在触发时冻结以下信息：
   - 标签种类；
   - 标签标题；
   - 选中状态；
   - 标签矩形；
   - 浮窗目标矩形；
   - 浮窗草稿和当前可见内容。
3. 无动画插入全区域临时画布，Genie 收束进度设置为 `1`。
4. 前景标签副本保持清晰；临时浮窗在标签矩形内完全收束且末段透明。
5. 收束进度从 `1 → 0`：
   - 临时浮窗从标签后方出现；
   - 远离标签的上边先向上和两侧展开；
   - 靠近标签的底边短暂保持收窄；
   - 中段沿标签中心方向弯曲；
   - 完整浮窗内容与外壳共同被采样和拉伸。
6. 背景模糊与暗色遮罩随 `1 - progress` 渐入，键盘不参与。
7. 到达 `progress = 0` 后，在禁用隐式动画的同一事务中：
   - 移除临时 Shader 图层；
   - 显示同位置、同尺寸的真实交互浮窗。

最后一帧不使用两层半透明表面的交叉淡化。

### 3.3 收回路径

收回触发来源：

- 点击当前前景标签：取消；
- 点击关闭按钮：取消；
- 点击模糊背景：取消；
- 点击“完成”：提交；
- 银行卡选择账户或“暂时不记”：提交。

流程：

1. 记录提交或取消意图，锁定浮窗和键盘输入。
2. 在禁用隐式动画的同一事务中，用当前草稿内容的临时合成图层替换真实浮窗，
   并设置 `progress = 0`。
3. 收束进度从 `0 → 1`，严格复用打开时的映射。
4. 浮窗底边首先向标签宽度收窄，中段随后弯曲，顶边最后汇入。
5. 临近标签的最后阶段，临时图层淡出到透明，前景标签副本始终清晰。
6. 动画完成后：
   - 提交路径一次性写回正式表单；
   - 取消路径丢弃草稿；
   - 移除临时画布与标签副本；
   - 恢复真实标签行和主键盘路由。

### 3.4 标签行为

- 当前标签在浮窗完全展开后保持清晰可见。
- 仅在 `.presented` 阶段允许再次点击；动画中忽略重复点击。
- 再次点击等价于取消，不提交浮窗草稿。
- 标签副本使用打开瞬间冻结的标题和宽度，关闭路径不会因草稿变化跳动。
- 提交完成后，真实标签可以显示新的账户名、AA 金额、组合账户名或优惠金额。
- 其他标签在当前浮窗关闭前不可交互，不自动切换。

### 3.5 背景与键盘

- 模糊和遮罩仅覆盖键盘上方的记账内容。
- 默认暗色遮罩最终不透明度为 `18%`。
- 正常透明度模式使用系统材质，并以动画进度控制其显现。
- “降低透明度”开启时，改用更实的系统背景色，不执行重度实时模糊。
- 键盘在 `.opening` 和 `.closing` 阶段锁定。
- 键盘在 `.presented` 阶段恢复，并按现有规则路由：
  - 银行卡：主金额；
  - AA：总人数；
  - 组合支付：当前付款项金额；
  - 优惠：优惠金额。

## 4. 技术架构

### 4.1 视图树

```text
EntryComposerView
├── EntryComposerContent
│   └── 原 EntryContextControls（布局占位，背景层）
├── EntryGlassKeypad（永不进入 Shader）
└── EntryContextOverlayHost
    ├── 背景点击层
    ├── 真实 EntryContextOverlayPanel（仅 presented）
    ├── EntryContextGenieCanvas（仅 opening / closing）
    │   └── 合成后的 EntryContextTransitionPanel
    └── EntryContextSourceTagOverlay（active 期间）
```

### 4.2 组件职责

#### `EntryContextPresentationState`

负责：

- 当前标签类型；
- `.closed / .preparing / .opening / .presented / .closing` 阶段；
- Genie 收束进度；
- 冻结的来源标签视觉模型；
- 来源和目标矩形；
- 草稿、输入目标、关闭意图；
- 动画重入与异常恢复。

收束进度统一定义：

```text
0 = 浮窗完全展开
1 = 浮窗完全收束到标签
```

打开为 `1 → 0`，关闭为 `0 → 1`，避免 Shader 内再反转语义。

#### `EntryContextSourceTagOverlay`

负责：

- 在来源矩形重绘与原标签一致的冻结副本；
- 置于背景模糊和 Genie 图层上方；
- `.presented` 时接收再次点击并触发取消；
- 提供稳定的 VoiceOver 标签和关闭提示。

不读取正在编辑的草稿，不随提交结果改变宽度。

#### `EntryContextGenieCanvas`

负责：

- 覆盖键盘上方的完整可用区域，而不是只包住浮窗；
- 在目标矩形绘制转场专用浮窗；
- 使用 `.compositingGroup()` 将外壳和内容合成为单一图层；
- 仅在开合期间应用 `layerEffect`；
- 把画布尺寸、来源矩形、目标矩形和进度传给 Metal；
- 不承载任何业务交互。

#### `EntryContextTransitionPanel`

继续作为真实浮窗的渲染副本，但必须：

- 显示完整标题、按钮、输入内容和当前可见列表；
- 与真实浮窗使用同一尺寸、圆角、颜色、间距和内容数据；
- 不再分阶段隐藏内部内容；
- 不包含原生交互和辅助功能树；
- 在动画开始前冻结，动画中不响应数据变化。

#### `EntryContextOverlayPanel`

保持真实交互职责。只有在 `.presented` 阶段显示并允许交互。

### 4.3 Metal Shader

新 Shader 使用 `SwiftUI::Layer`：

```metal
[[ stitchable ]] half4 entryContextGenieLayer(
    float2 position,
    SwiftUI::Layer layer,
    float2 canvasSize,
    float4 panelRect,
    float4 tagRect,
    float progress
)
```

参数坐标全部属于 `EntryContextCoordinateSpace` 对应的动画画布。

映射策略必须可直接反算，禁止逐像素迭代搜索：

1. 根据 `progress` 在线性纵向范围内混合面板顶边/底边与标签顶边/底边。
2. 从输出像素的纵向位置精确恢复源图层归一化行 `v`。
3. 以 `v` 计算局部收束进度：
   - `v = 1` 的底部领先收束；
   - `v = 0` 的顶部稍后收束。
4. 每一行分别计算：
   - 当前中心点；
   - 当前半宽；
   - 指向标签中心的正弦弯曲。
5. 从当前行的输出横坐标恢复源面板列 `u`。
6. 采样 `panelRect` 内对应的源像素。
7. 输出范围之外返回透明。
8. `progress` 接近 `1` 时淡出临时图层，避免标签下残留压缩纹理。

初始手感参数：

| 参数 | 初始值 | 允许校准范围 |
| --- | ---: | ---: |
| 动画时长 | `0.62s` | `0.55–0.70s` |
| 时间曲线 | `(0.22, 0.72, 0.18, 1.0)` | 真机分帧后微调 |
| 底部提前收窄 | `1.35` | `1.00–1.80` |
| 横向收窄指数 | `1.70` | `1.30–2.20` |
| 中段弯曲 | `0.18` | `0.08–0.28` |
| 终点淡出起点 | `0.84` | `0.80–0.90` |

Shader 不执行模糊，不创建循环，不读取业务状态。

### 4.4 画布和裁切

- 画布覆盖键盘上方的完整可用区域，并包含来源标签矩形。
- 标签、目标浮窗和画布使用同一命名坐标空间。
- 浮窗横向滚动后的标签位置必须重新读取。
- `layerEffect` 的采样范围从最小安全值开始；若真机出现裁切，只增加到来源和
  目标矩形的最大必要位移，不使用无条件全屏巨量 padding。
- 安全区、横竖屏、iPad 尺寸和动态字体变化后重新测量。

## 5. 状态和数据流

### 5.1 打开

```text
closed
→ prepare(kind, frozenTag, draft)
→ preparing(progress = 1)
→ 收到 targetFrame
→ opening(progress 1 → 0)
→ 原子切换
→ presented
```

### 5.2 关闭

```text
presented
→ beginClosing(intent, progress = 0)
→ 原子切换到临时图层
→ closing(progress 0 → 1)
→ apply or discard draft
→ closed
```

### 5.3 中断

- 动画期间不允许新标签、键盘或浮窗输入。
- App 进入后台或尺寸突变时，不保留中间状态：
  - 打开中安全落到 `.presented`；
  - 关闭中完成既定提交或取消并落到 `.closed`。
- 来源标签或目标矩形无效时，使用同锚点的轻微缩放和淡入淡出降级。
- 不从逻辑目标值重新启动正在进行的动画，避免第一帧跳变。

## 6. 无障碍

- “减少动态效果”开启时：
  - 不调用 Metal；
  - 使用 `0.20s` 轻微锚点缩放和淡入淡出；
  - 保留背景、键盘、提交和取消语义。
- “降低透明度”开启时使用更实背景。
- 动态字体导致浮窗过高时，内部滚动，完成按钮保持可达。
- 动画层和背景原标签从辅助功能树隐藏。
- `.presented` 后 VoiceOver 焦点进入浮窗标题。
- 关闭后焦点返回真实来源标签。
- 前景标签副本的提示为“再次轻点关闭并取消修改”。

## 7. 性能策略

1. Shader 只存在于 `.opening` 和 `.closing`。
2. 只合成键盘上方的动画画布，键盘不进入纹理。
3. 转场浮窗在动画开始前冻结，过程中不重复构建昂贵业务对象。
4. Shader 使用闭式反算，不使用逐像素二分搜索。
5. 背景模糊独立于 Shader，使用系统合成材质。
6. 动画完成后销毁临时图层，不保留持续 GPU 成本。
7. 以真机录屏和 Instruments hitch 检查为准，不以 Simulator 流畅度代替。

## 8. 测试与验收

### 8.1 状态测试

- 打开进度严格为 `1 → 0`，关闭为 `0 → 1`。
- 当前标签再次点击产生取消意图。
- 其他标签在 active 状态无法启动第二个浮窗。
- 提交只在关闭动画完成后写回。
- 取消丢弃草稿。
- AA 人数、组合支付、优惠和银行卡键盘路由保持现状。
- 后台和尺寸中断不会留下半展开状态。

### 8.2 UI 测试

- 四种浮窗均从各自标签展开并收回同一标签。
- 浮窗打开时当前标签清晰可见且可点击取消。
- 其他标签不可点击。
- 键盘在开合期间锁定，在展开后恢复正确输入目标。
- 打开和关闭后无重复面板、残留图层或错误焦点。
- “减少动态效果”和“降低透明度”路径可用。

### 8.3 视觉分帧

逐帧检查 `0% / 25% / 50% / 75% / 100%`：

- 起点只有清晰标签，不出现白色缩略块；
- 底边比顶边更早收窄；
- 中段存在连续轻微弯曲；
- 完整内容同步形变；
- 没有黑边、裁切和单像素残留；
- 真实浮窗与临时图层切换帧无亮度跳变；
- 收回是打开路径的严格反向。

### 8.4 性能

- 真机连续开合 AA、优惠、组合支付和银行卡各十次。
- 60 Hz 设备以稳定 `60fps` 为最低目标。
- ProMotion 设备尽量跟随系统刷新率。
- 录屏和非录屏两种状态均检查明显 hitch。
- Instruments 确认转场结束后不保留临时 Metal 图层。

## 10. 完成定义

只有同时满足以下条件才算完成：

1. 真正使用 `layerEffect` 对完整合成浮窗逐像素形变。
2. 当前标签始终清晰可读，并可再次点击取消收回。
3. 其他标签锁定，键盘保持清晰且路由正确。
4. 完整内容参与漏斗形弯曲，不使用外壳展开加内容淡入。
5. 开合使用同一映射，最后一帧没有闪烁或跳变。
6. 减少动态效果、降低透明度和异常恢复可用。
7. 真机构建、功能回归、视觉分帧和性能检查通过。
