# 标签浮窗与键盘边界羽化设计

日期：2026-08-01  
状态：已确认并实施  
范围：记账页“银行卡、AA、组合支付、优惠”浮窗打开期间的键盘上边界

## 1. 问题

标签浮窗打开后，键盘上方的记账内容被模糊并压暗，键盘则保持清晰。两层目前在
键盘顶部以一条笔直的水平线硬切，亮度和材质同时突变，产生明显割裂感。

## 2. 已确认决策

采用“键盘上方单侧羽化”方案：

- 羽化带完全位于键盘顶部边界之上，不进入键盘区域；
- 键盘背景、所有按键、文字、触控区域和输入响应保持现状；
- 不修改已经验收的 Genie Shader、浮窗位置或标签交互；
- 羽化只在四类 Genie 浮窗处于活动状态时显示，并随背景遮罩进度同步开合。

## 3. 视觉设计

在键盘顶部边界上方建立一条 `44pt` 高的过渡带：

1. 过渡带上沿与现有模糊、压暗背景完全一致；
2. 从上到下逐渐减弱黑色压暗量与材质可见度；
3. 临近键盘的最后 `12pt`，颜色逐渐靠近键盘容器的背景色；
4. 到达键盘顶部边界时，过渡带结束，键盘从第一个像素开始保持原有清晰材质；
5. 不增加硬分隔线、明显阴影或进入键盘的模糊。

羽化使用非线性渐变：上半段变化较慢，下半段柔和加速，以避免产生一条新的可见
“渐变起点”。深色模式使用系统语义颜色计算，不写死白色。

## 4. 层级与实现边界

```text
浮窗与固定源标签
────────────────
模糊、压暗的记账内容
键盘上方 44pt 单侧羽化带
────────────────  键盘顶部边界
清晰且可交互的 EntryGlassKeypad
```

羽化带属于键盘上方的背景遮罩层，不属于键盘，也不进入 Genie 临时画布。它应：

- 读取现有 `contextPresentation.backdropProgress`；
- 与背景模糊、压暗同步出现和消失；
- 不接收点击，不进入辅助功能树；
- 不改变键盘布局高度、圆角、内边距或命中区域；
- 只使用系统材质、语义颜色、透明度和渐变遮罩，不新增逐帧 Shader 或模糊计算。

“降低透明度”开启时，不使用实时材质；改用系统背景色与相同的单侧透明度渐变，
同时保持边界柔和。

## 5. 性能与动态效果

- 羽化带是固定尺寸的合成层，动画期间只改变透明度；
- 不对键盘或完整页面追加新的实时模糊；
- 不改变当前 `0.62s` Genie 动画与其进度方向；
- 减少动态效果不需要额外降级，因为该过渡不发生空间位移；
- 浮窗关闭后从视图层级移除羽化带。

## 6. 验证

### 功能

- AA 打开后键盘仍直接输入总人数；
- 优惠与组合支付仍能使用键盘输入；
- 银行卡、AA、组合支付、优惠均可正常打开、提交、取消和沿原路径收回；
- 羽化带不遮挡固定源标签，也不拦截任何点击。

### 视觉

- 截图中不再出现贯穿屏幕的灰白硬切线；
- 键盘顶部及全部按键保持清晰，没有被模糊或蒙灰；
- 羽化上沿不可辨认出新的水平分界；
- 浅色、深色与“降低透明度”模式均无色块、黑边或闪帧。

### 性能

- Genie 动画帧率不因羽化带下降；
- 羽化不触发键盘重布局；
- 动画完成后不存在持续运行的额外效果层。

## 7. 验收标准

1. 羽化区域严格位于键盘上方，高度为 `44pt`，不侵入键盘。
2. 键盘视觉、输入逻辑、响应速度与修改前一致。
3. 上下区域由柔和材质渐变连接，不再出现截图中的强水平割裂。
4. 四类 Genie 浮窗的开合路径、末帧连续性和固定源标签行为保持不变。
5. 真机构建、交互回归与截图对比通过。
