# 交易手续费模板设计

## 目标

在支出、收入、转账和换汇记账中统一提供“手续费”入口。手续费属于同一笔交易的结构化关联信息，不生成独立流水。

## 记账口径

### 收入

- 用户先输入手续费前金额。
- 比例或定额手续费从该金额中直接扣除。
- 账户余额和收入统计只增加扣费后的实际收入。
- 手续费不计为收入，也不计为支出。
- 流水主金额显示实际收入，下方仅显示“手续费 金额”。

示例：输入 1000，应用 0.38% 后，实际收入为 996.20，关联手续费为 3.80。

### 支出

- 主金额保持用户输入的主要消费金额。
- 手续费作为同一交易的关联信息。
- 账户余额减少“主金额 + 手续费”。
- 支出统计计入“主金额 + 手续费”。
- 流水主金额仍显示主要消费金额，下方显示“手续费 金额”。

### 转账与换汇

- 沿用现有逻辑：手续费从选择的手续费账户额外扣除。

## 手续费模板

- 模板包含名称、比例和适用交易类型。
- 首个系统预置模板为收入模板“闲鱼手续费”，比例 0.38%。
- 用户可以新增、修改或删除自己的比例模板。
- 比例计算按照当前币种支持的小数位四舍五入。

## 浮卡交互

- “手续费”标签在支出、收入、转账和换汇中呈现。
- 浮卡沿用现有标签浮卡的屏幕居中逻辑和 95% 不透明度。
- 顶部为手动输入区，左侧按钮在“比例”和“定额”之间切换，右侧只输入数字，不显示货币符号。
- 中间依次显示适用于当前交易类型的手续费模板和“管理手续费模板”。
- 底部为“取消”和“完成”。
- 手动输入只在点击“完成”后应用。
- 点击模板后立即计算、应用并关闭浮卡。
- 点击浮卡外区域取消本次编辑。

## 金额编辑

- 收入保存手续费计算前的基准金额和扣费后的实际收入，避免重复扣减。
- 重新打开手续费卡可以修改比例或定额手续费。

## 流水与详情

- 流水只显示一条交易。
- 主金额遵循收入/支出的口径。
- 下方完整显示“手续费 金额”，不显示手续费前金额、模板名称或百分比。
- 交易详情保留手续费金额和收入的手续费前金额。

## 验证

- 单元测试覆盖比例计算、货币精度、收入净额、支出总影响和模板应用。
- UI 测试覆盖四种交易类型的手续费入口、比例/定额切换、模板即时应用及取消/完成。
- 流水测试验证主金额与手续费附加信息。
