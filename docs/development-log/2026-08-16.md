# 2026-08-16 开发日志

## 记账编辑器修复

- 修复顶部“收入 / 转账 / 换汇”无法点击：将下拉关闭拖拽手势限制在拖拽把手，避免覆盖交易类型选择器。
- 新增“设置 → 快捷记账”开关；开启后，点击“记一笔”会自动展开分类。
- 移除子分类浮层打开时的背景变暗效果。
- AA 浮卡将“其他人合计应还”调整为“其他每人应还”，并展示按总人数均分后的金额。
- 将“报销 / AA / 优惠”与“组合支付 / 手续费 / 不计支出”分为两组，以虚线分隔。
- 修复优惠浮卡遮挡编辑器数字键盘的问题。

## 布局修复

- 统一收入、转账、换汇与支出的编辑器顶部锚点，交易类型条位于拖拽把手下方。
- 无论分类是否展开，表单区域都可滚动，数字键盘固定在底部；“下一笔 / 完成”不再被屏幕裁切。

## 转账与购汇流程

- 支出页在“不计支出”与数字键盘之间补充虚线分隔。
- 转账页移除重复的“账户”项，只保留“转出账户 / 转入账户”。
- “换汇”统一调整为“购汇”：来源限定为购汇银行卡，购入时仅选择购入币种、汇率、优惠与手续费。
- 购入币种默认归入所选银行卡；该币种尚未启用时，会在启用前提示用户确认。
- 新增“购入现金”选项：目标币种归入既有现金账户，未启用时同样先提示；若没有现金账户则引导用户先创建，不会额外生成现金账户。
