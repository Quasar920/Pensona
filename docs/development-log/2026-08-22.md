# 2026-08-22 开发日志

## 退款与退款差额

- 重构关联退款的记账规则：用户填写的退款金额完整记为“退款”；当退款超过原实际支出时，仅将差额显示为“退款收入”。
- 原支出以优惠后的实际支出为准；例如原价 ¥5、优惠 ¥2、实际支出 ¥3，退款 ¥10 时生成“退款 ¥10”及“退款收入 +¥7”。
- 原支出退款后归零，并保留原价删除线、优惠和“退款差额”信息，避免优惠金额参与退款差额计算。
- 新增默认分类“其他收入 / 退款收入”，用于退款差额的展示与统计。
- 扩展退款关联模型和迁移/备份兼容逻辑；退款差额为关联退款的展示数据，不重复写入钱包余额。

## 账页与交互

- 流水卡片统一为矩形圆角卡片；关联退款和退款收入合并在同一张矩形卡片中，不再显示“关联退款”或“原支出”等额外标题。
- 关联卡保留左右滑动操作：左、右滑分别可展开“编辑”和“删除”。修复横向滑动时误打开账单详情的问题；只有普通点击才打开详情。
- 退款保存后自动回到账页。
- 流水分类名称改为常规黑色字重，移除加粗样式；同步收敛流水图标、文字与数字的显示密度。
